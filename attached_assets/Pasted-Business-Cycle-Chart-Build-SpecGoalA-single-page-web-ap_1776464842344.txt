Business Cycle Chart — Build SpecGoalA single-page web app that shows one chart: a custom macro composite ratio with SPX overlaid on top, weekly timeframe, back to 1959. Recession bars shaded in the background. Trendline and parallel channel drawing tools. Password-protected, deployed on Replit.Tech stack
Frontend: React 18 + Vite + TypeScript, Tailwind CSS
Chart: lightweight-charts v5 (Apache 2.0, free)
Drawing tools: lightweight-charts-drawing from github.com/deepentropy/lightweight-charts-drawing (supports TrendLine and ParallelChannel, works with lwc v5, has export/import for persistence)
Backend: Node 20 + Express + TypeScript
Storage: SQLite via better-sqlite3 (single file, persists across Replit deploys)
Deploy: Replit Autoscale Deployment

This sets the start date of the chart.The formulaBusiness Cycle Composite value per week:composite = (SPX × FEDFUNDS × CPIAUCSL) / (UNRATE² × M2SL)Where UNRATE² means UNRATE × UNRATE.Unit handling: whatever the raw FRED values return. Don't normalize. The shape of the line is what matters, not the absolute number.Data alignmentThis is the most important part of the build. Get it right.
All FRED series are monthly (first day of month). SPX is weekly (Yahoo returns weekly bars, use close of each week).
Resample everything to weekly, Friday-close:

For SPX, use Yahoo's weekly bars directly (close values)
For each FRED series, forward-fill the monthly value across every Friday in that month. So if UNRATE for March 2024 is 3.8, every Friday in March 2024 gets the value 3.8. Next new value arrives in April.


Build the composite time series: for each Friday from 1959-01-02 through last completed Friday, compute the formula using the aligned values.
Skip weeks where any input is null (should only affect the earliest weeks if FRED series don't all start on the exact same day).
Recession barsUSREC is a monthly 0/1 flag. Convert to intervals:
Walk the series; each contiguous run of 1s becomes one { start, end } interval (unix seconds)
Render each interval as a semi-transparent gray vertical rectangle spanning the chart's full y range using a Pane Primitive from lightweight-charts

Refresh button behavior
Click → POST /api/refresh → loading spinner on the button
On success, replace chart data, update last-updated timestamp
Drawings stay on screen untouched, since they're anchored to time+price coordinates
On error, toast message "Refresh failed, showing cached data"
Drawing tools behavior
Select tool: click an existing drawing to select it, drag handles to edit, press Delete key to remove
Trendline: click two points
Parallel channel: click three points (two for the main line, third sets channel width)
Every time a drawing is created, moved, or deleted → debounced 500ms → POST full drawings JSON to /api/drawings
On page load, GET drawings and hand the JSON to DrawingManager.importDrawings()
